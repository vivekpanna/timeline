# Timeline Tool Skill Set

Workspace skills for building an original, free browser-based timeline editor informed by user needs and public product references.

## Skills and handoffs

1. `timeline-product-discovery`: collect bounded evidence and define the MVP.
2. `timeline-editor-design`: turn the brief into workflows, states, and a data contract.
3. `timeline-editor-build`: implement the editor and its local-first data paths.
4. `timeline-editor-verify`: validate user outcomes, exports, accessibility, and responsive behavior.

Use only the stages needed for the request. For an implementation task, discovery/design can be brief when requirements are already clear; verification remains scoped to the change. Each skill is independently usable from its `SKILL.md` under `.agents/skills/`.

## Starting product boundary

Public Lucen Timeline Online material describes timeline, roadmap, and swimlane views, presentation-ready visuals, sharing, integrations, and native PowerPoint export. Its public pricing page describes a free individual plan and premium collaboration/integration features. The online editor redirects to sign-in, so its authenticated behavior has not been inspected here. These are discovery inputs, not a complete requirements spec.

Start with a genuinely usable free solo workflow: create and edit tasks/milestones, organize lanes, save/reopen without an account, and export in a dependable open format. Add cloud collaboration, integrations, or PowerPoint only when explicitly prioritized and properly validated. Build a functionally comparable product with original code, UI, copy, and assets; do not reproduce proprietary screens or branding.
